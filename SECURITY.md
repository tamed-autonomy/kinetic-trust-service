# Security Policy

## Supported versions

`main` and the latest published package release, if any, are maintained.
Before the first package publication, this means `main` only. Older package
releases do not receive routine fixes.

## Reporting a vulnerability

Report suspected vulnerabilities privately to security@tamedautonomy.ai. Do
not disclose vulnerability details in a public issue, discussion, or pull
request.

Include the affected revision and component, impact, reproduction conditions,
and known mitigation. Do not include live credentials or another person's
data. Receipt, investigation, and remediation are best effort; there is no
response or repair service-level objective.

Tests, vectors, package checks, and CodeQL are bounded evidence about exercised
behavior. They are not deployment certification, application conformance, or
proof that a consuming product is secure. Products remain responsible for
authenticity, completeness, configuration, credentials, storage, transport,
key custody, failures, retry, human interaction, action, and enforcement.
